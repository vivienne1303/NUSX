# NUSX Club

Responsive landing page using the supplied logo. Open `index.html` in a browser, or serve this folder with `python -m http.server 3000` and visit http://localhost:3000.

Built with HTML, CSS and JavaScript; no installation or build required. Includes animated globe, continuous marquee, scroll reveals, count-up statistics, mobile navigation, event dialogs and reduced-motion support. Google Fonts is optional; system fonts work offline.

The provided 2025 events are displayed as archived events. Membership, contact and social buttons explain that official links are pending; replace these handlers in `script.js` when real URLs are available. No membership data is collected.
